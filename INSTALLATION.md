## Installation Instructions
1. **Download** the `.zip` file from [Releases](https://github.com/problaze20/xcm/releases)

> [!NOTE]  
> Safari automatically unzips `.zip` files if the **“Open ‘safe’ files after downloading”** setting is enabled.
> If that’s the case, you can skip step 2.

2. **Unzip** the downloaded `.zip` file (if it wasn’t unzipped automatically).

3. (IMPORTANT)  
   Choose one of the following options depending on your setup:

   **Option A — Direct Launch:**
   - Open the unzipped folder and **double-click the app** to run it.
   - If macOS shows a warning saying the app is from an unidentified developer:
     1. Right-click the app and choose **Open**.  
     2. Click **Open** again in the dialog that appears.

    **Option B — Allow App from an Unidentified Developer:**
   - If macOS shows a message saying the app **“can’t be opened because it’s from an unidentified developer”**:
     1. Open **System Settings → Privacy & Security**.  
     2. Scroll down to the bottom of the page.  
     3. You’ll see a message about your app — click **Open Anyway**.  
     4. When prompted, confirm by clicking **Open** again.  
   - The app should now launch successfully.
